01 / 課題の理解

「毎回ゼロから組む」制作フローを、
検証可能な仕組みに変えたい。

ご依頼内容を拝見し、単なる「AIでコードを書く」ツールではなく、 再現度・修正時間・費用のバランスを検証したうえで現場に導入する、 地に足のついた仕組みづくりを求めていらっしゃると理解しました。

LP・地域別ページを量産する中で、デザインJPGからのコーディングが毎回工数のボトルネックになっている。

→ OCR・素材抽出・コード生成の自動化ラインを構築

人物と背景が重なる部分や、文字に隠れた素材など、単純な切り出しでは再現できない領域がある。

→ 背景補完・代替素材生成＋人の確認フローを明示

ChatGPT系・Claude系のどちらが実務に適しているか、再現度・時間・費用で比較判断したい。

→ 同一画像・同一条件でのA/B検証レポートを提出

WordPressに組み込みやすく、地域名や文章を差し替えても崩れない、保守しやすいコードが欲しい。

→ セクション独立CSS設計＋可変テキスト前提の実装
02 / Kairosが提供できる価値

「検証して選ぶ」ための、5つの実装アプローチ

再現度・修正時間・費用を数値で比較できる形に落とし込み、本開発の判断材料をそろえます。

01

原稿の読み取り・編集可能化

画像内の見出し・本文・料金等をOCR＋AIで構造化し、誤読箇所を確認・修正できる形でテキスト化します。

02

人物・背景の素材切り出し

セグメンテーションで人物・背景・アイコンを分離。重なり・隠れ部分は背景補完や代替生成で対応範囲を明確化します。

03

HTML・CSSの自動生成

色・余白・文字サイズを解析し、他セクションに影響しにくい設計でコードを生成。WordPress組み込みも想定した構成にします。

04

Playwrightによる自動比較

生成ページのスクリーンショットを元画像と比較し、文字欠け・崩れ・はみ出し・ボタン動作を自動検知します。

05

API管理とコスト可視化

APIキーをサーバー側に隠蔽し、1件あたりの利用料・累計利用量を可視化。使いすぎを防ぐ上限設定も組み込みます。

03 / 進め方・スケジュールイメージ

まずは小規模検証で、方式を見極める

いきなり本開発に進まず、ご提供いただくヒーローセクション画像数枚での検証から着手します。

PHASE 01 約1〜2週間

検証・方式比較

  • オンライン打ち合わせで要件・運用を確認
  • ChatGPT系／Claude系＋画像処理APIを比較
  • 原稿読み取り精度・素材切り出し範囲を検証
  • 所要時間・API費用・課題を報告書にまとめる
PHASE 02 検証結果を踏まえ見積もり

本開発

  • アップロード〜生成〜修正〜出力までのツール実装
  • PC／スマホ推定レイアウトの確認・修正UI
  • Playwright連携の表示検証フロー組み込み
  • WordPress組み込みを想定した出力構成に整備
PHASE 03 継続運用

納品・保守

  • ソースコード・操作手順・環境構築資料を納品
  • API利用料・維持費の試算と使いすぎ防止設定
  • 納品後の修正・保守対応窓口を継続
  • 運用データを踏まえた精度改善の提案
04 / 最初の検証で確認すること

8つの観点で、数値とともにご報告します

  • 01原稿の読み取り精度（誤読率・修正量）
  • 02人物写真・背景の切り出し／再利用可能範囲
  • 03画像補完・代替生成が必要な箇所の特定
  • 04デザイン再現度（レイアウト・配色・余白）
  • 05初稿生成〜人による確認完了までの所要時間
  • 061件あたりのAPI利用料（画像処理・生成含む）
  • 07手作業との比較で短縮できた／できなかった工程
  • 08自動化が難しく人の判断が必要な部分
